# おかぽ会社 — 3D本部探索

既存サイトにそのまま配置できる、HTML / CSS / JavaScript の独立した3D探索ページです。ログインやAPIキーは不要です。Three.js 0.180.0 を `vendor/` に同梱しています。

## 開き方

既存の静的サイトと一緒に公開すると `/company/` または `/company/index.html` で利用できます。ゲーム一覧にも入口を追加しています。

ローカル確認には Node.js が必要です。

```sh
cd company
npm run dev
```

表示された `http://127.0.0.1:4173/` を開きます。ブラウザのES Modulesを使用するため、HTMLファイルの直接ダブルクリックではなく HTTP / HTTPS 経由で開いてください。

## 操作

| 操作 | 入力 |
| --- | --- |
| 探索開始 | 「本部を探索する」をクリック |
| 前後左右に移動 | WASD または矢印キー |
| 見回す | マウス |
| 速く歩く | Shift + 移動 |
| 社員に話しかける / ドア開閉 | 近づいて E |
| 一時停止 / マウス解放 | Esc |
| 俯瞰表示 / 入口へ戻る | 一時停止メニュー |
| 左右を向く | Q / R（補助操作） |
| 画質 / マウス感度 / 環境音 | 右上の設定ボタン |

ポインターロックが使えない環境では、ドラッグによる視点操作に切り替わります。マウス固定中はEscで解除してから画面のボタンを操作します。

### iPhone・タッチ操作

- 左下の赤い移動パッドを押したまま、行きたい方向へ動かします。指を離すと停止します。
- 画面の空いている場所をドラッグすると見回せます。移動と見回しは2本の指で同時に操作できます。
- 社員やドアに近づくと、右下に会話・開閉ボタンが表示されます。
- 「速く歩く」はタップで切り替え。「メニュー」から停止・再開・入口へ戻れます。
- タッチ端末と幅700px以下の画面では操作パッドを表示します。iPhoneではマウス固定を要求しません。
- 縦向き・横向き、セーフエリア、ブラウザの表示領域変化に対応。回転・失焦・タブ切り替え・メニュー表示で入力を解除します。
- タッチ端末の自動画質は、影なし・描画解像度1倍までの軽量設定で開始します。

## 実装

- 中央司令室は幅32m × 奥行34m。左右に幅9m × 奥行16mのサーバールーム・資料室を配置。
- 広い中央通路、周回できる八角形の司令卓、社長の壇上へ続く正面と側面のスロープ。
- 社員5名。社長「おかぽ」は正面奥の目立つ位置に置き、サングラスとコートを着用。本人から見た左側（ローカル +X）には腕・手・袖を生成しません。
- 4人の社員は提供画像をもとに個別モデル化。警備員はベレー帽・サングラス・スコープ付き装備で見回し、黒フードのハッカーは四角い眼鏡をかけて着席し、ノートPCで左右の手首と指を交互に動かします。黒金の柄スーツの企画担当は手振り、金髪・葉巻・茶色のファーコートの管理補佐は書類確認と小さな煙の動きを持ちます。
- 社員はその場で動くため通路へ移動しません。装備や毛皮を含む外形に衝突範囲を合わせ、髪・眼鏡・キーなど固定部品はまとめて描画します。
- ロゴはサングラスをかけた顔だけのシンボル。触手やタコの形状はありません。
- デスク、モニター、資料棚、サーバーラック、マグカップ、書類、照明、ホログラムを低ポリゴンで構成。
- スライドドア、社員プロフィール、現在地と訪問済み部屋を示すミニマップ。
- 円形プレイヤーと家具・壁の衝突判定。移動を細分化してすり抜けを防ぎ、壁沿いには滑らかに移動。開口部にいる場合はドアを閉鎖しません。
- 静的な形状のインスタンス描画、共有マテリアル、上限1.5倍の描画解像度、軽量モードでは影を無効化。自動画質は実測フレーム時間をもとに軽量化。
- ブラウザの低モーション設定を尊重。失焦・タブ非表示・ポインターロック解除時に移動入力をクリア。WebGLエラー表示あり。
- テキストとモニターは手続き生成。3D素材の追加ダウンロードは不要。Google Fontsの取得に失敗してもシステムフォントで動作します。
- 任意の環境音はブラウザ内で合成し、初期状態はオフです。

## 組み込み

`company/` ディレクトリを同じ構造で配置するか、`npm run build` で生成した `dist/` の内容だけを任意のディレクトリに配置できます。すべてのページ内参照は相対パスです。

```html
<iframe
  src="/company/"
  title="おかぽ会社 3D探索"
  style="width:100%;height:85vh;min-height:550px;border:0"
  allow="fullscreen"
  allowfullscreen>
</iframe>
```

iframeに `sandbox` を追加する場合は、`allow-scripts allow-same-origin allow-pointer-lock` が必要です。直接ページを開いた場合もiframe内でも、視点の固定は訪問者のクリック後に要求します。

| ファイル | 役割 |
| --- | --- |
| `index.html` | 探索画面、各ダイアログ、エラー表示 |
| `style.css` | 黒・赤のUI、画面サイズ対応 |
| `logo.svg` | 顔だけのシンボル |
| `js/main.js` | 操作、ミニマップ、会話、画質調整、音 |
| `js/touch-controls.js` | 指ごとの移動・視点操作、キャンセル時の入力解除 |
| `js/scene.js` | 3D空間、家具、社員、照明、アニメーション |
| `js/employees.js` | 4人の個別モデル、関節・指の動き、部品の描画統合 |
| `js/layout.js` | 共通レイアウト、社員データ、移動と衝突 |
| `assets/gold-brocade.png` | 生成した黒金のスーツ用テクスチャ。背景で読み込み、取得失敗時も探索は継続 |
| `vendor/` | 固定バージョンのThree.jsとMITライセンス |
| `tests/explorer.test.mjs` | 到達性、衝突、ドア、モデル構成のテスト |
| `tests/touch-controls.test.mjs` | 同時操作、入力解除、アナログ移動、衝突、PCドラッグのテスト |
| `scripts/serve.mjs` | ローカル確認用サーバー |
| `scripts/build.mjs` | 必要な公開ファイルのみを `dist/` にコピー |
| `.openai/hosting.json` | この探索ページのSites公開設定 |

上位サイトの変更は `games/index.html` の探索カードと `sitemap.xml` のURL追加です。既存のゲーム一覧の編集内容は保持しています。

## 検証

```sh
npm test
npm run build
```

12のNode.jsテストで、社員5名と社長の左腕なし、実際のThree.jsによるジオメトリ構築、全社員・両小部屋への到達性、開閉ドア、壁や家具への衝突、大きい移動量によるすり抜け防止、壁沿いの移動、スロープと部屋判定を検証します。社員の特徴・両腕、アニメーションと低モーション設定、指先が実際のキーボード上にあること、40秒間の動きの外形が衝突範囲内に留まることも確認します。椅子・柱・植木・小部屋の机も経路判定に含めています。

タッチ操作用の5テストと合わせて17テストを実行します。WebGLの実描画、iPhone実機でのFPS、ポインターロックのブラウザ操作はこの自動テストには含まれません。WebGL 2・Pointer Eventsが使えるSafariなどのスマートフォンブラウザとPCブラウザを対象としています。
