Claude Codeで初心者がWebサイトを作ってみた｜おかぽるLAB制作記

2026.08.26 公開

はじめに

「AIを使えば、プログラミング初心者でもWebサイトを作れるのか？」

そんな疑問から、実際にWebサイトを作ってみることにしました。

今回使ったのは、AnthropicのAIコーディングツール「Claude Code」です。

実際にClaude Codeを使って「おかぽるLAB」というWebサイトを制作し、GitHubとNetlifyを使って公開するまでの過程を紹介します。

プログラミングの専門家ではない自分が、AIに相談しながらどこまでWebサイトを作れるのか。実際の制作過程を記録します。

Claude Codeを使ってみようと思った理由

Webサイトを作るにはHTML、CSS、JavaScriptなどの知識が必要です。

そこで、AIに相談しながらWebサイトを作る方法を試してみることにしました。

「こういうWebサイトを作りたい」と自然な言葉で伝え、Claude Codeにコードの作成や修正を手伝ってもらいます。

作ったWebサイト「おかぽるLAB」

今回作ったのが「おかぽるLAB」です。

「AIで、見えない世界をカタチに。」をテーマに、AI、Web制作、ゲーム、植物など、自分が興味を持ったものを形にしていく場所として制作しています。

現在は、

  • AI関連コンテンツ
  • Web制作
  • オリジナルゲーム
  • おかぽるPLANTS
  • AIサービスの紹介

などを少しずつ追加しています。

サイトURL：https://okapo-site.netlify.app/

Claude CodeにWebサイトを作ってもらう

最初から完成形を作るのではなく、少しずつAIに指示を出しながら制作しました。

例えば、

  • 「黒を基調にした未来的なデザインにしたい」
  • 「AI・Web・ゲームなどをカテゴリごとに表示したい」
  • 「スマートフォンでも見やすくしてほしい」

といった形で、作りたいものを言葉で伝えます。

ブラウザで実際の表示を確認し、

  • 「ここをもう少し大きくしたい」
  • 「このボタンを右側に移したい」
  • 「スマートフォンでは1列にしたい」

など、修正点を再びClaude Codeに伝えます。

この繰り返しでサイトを作っていきました。

GitHubでコードを管理する

WebサイトのコードはGitHubで管理しています。

Claude Codeで変更したファイルをGitにコミットし、GitHubへPushします。

変更履歴が残るため、以前の状態を確認したり、問題が起きた場合に戻したりできます。

NetlifyでWebサイトを公開する

GitHubとNetlifyを連携し、GitHubに変更をPushするとWebサイトにも変更が反映される仕組みにしています。

制作の流れは、

Claude Code ↓ コードを修正 ↓ GitHub ↓ Netlify ↓ インターネット上に公開

という形です。

AIを使って実際にどこまで作れた？

実際にAIを使って、

  • HTMLの作成
  • CSSの調整
  • レスポンシブ対応
  • ページ追加
  • ボタンやリンクの修正
  • デザイン変更
  • Gitの操作確認
  • エラー調査
  • Webサイト改善

などを行いました。

さらに、オリジナルゲーム「オカリス」や観葉植物ショップ「おかぽるPLANTS」もサイトに追加しています。

実際に使ってみて分かったこと

一番感じたのは、「AIがあるからプログラミングを知らなくてもいい」というわけではないということです。

AIに正確な指示を出すには、自分が何を作りたいのかを理解する必要があります。

また、AIが変更したコードをそのまま信用するのではなく、実際にブラウザで確認することも重要でした。

AIに作ってもらう。 ↓ 自分で確認する。 ↓ 修正を依頼する。

この繰り返しが重要だと感じました。

AIを使うことで変わったこと

以前なら、「Webサイトを作りたい」と思っても、コードを書く知識が足りず、最初の段階で諦めていたかもしれません。

しかしAIを使うことで、「分からないから作れない」から、「分からないけど、とりあえず作ってみる」に変わりました。

AIにすべてを任せるのではなく、自分がアイデアを出し、AIに実装を手伝ってもらう。そんな使い方が、これから増えていくのではないかと思っています。

これからやりたいこと

おかぽるLABはまだ完成ではありません。

これから、

  • オリジナルゲームを増やす
  • おかぽるPLANTSの商品を増やす
  • AIツールの活用方法を紹介する

など、少しずつコンテンツを増やしていきます。

最終的には、「自分のアイデアをAIで可視化していく場所」にしていきたいと考えています。

まとめ

Claude Codeを使って実際にWebサイトを作ってみました。

GitHubやNetlifyなど、最初は分からないこともありましたが、AIに質問しながら一つずつ進めることで、実際にインターネット上で公開できるWebサイトを作ることができました。

Claude Codeは、プログラミングを知らなくても魔法のようにサイトを作ってくれるツールではありません。

しかし、

作りたいものを言葉にする ↓ AIに実装を手伝ってもらう ↓ 自分で確認する ↓ また改善する

という使い方をすれば、これまで作れなかったものにも挑戦できるようになります。

これからも、おかぽるLABでAIを使っていろいろなものを作っていきます。
