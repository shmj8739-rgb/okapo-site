# OKAPO MONEY CRASH

おかぽるLABのミニゲーム。紙幣を燃やす・破るだけの、シンプルな破壊系ゲームです。

タイムアタック・ミッション・ランク・実績などは持たず、「破壊した合計金額（TOTAL DESTROYED）」だけが増えていきます。

紙幣は実在の日本銀行券の写真をそのまま使うのではなく、**額面・配色の系統だけを踏襲した完全オリジナルのデザイン**（CSS/SVGでその場生成）です。実在紙幣の写真を切り出して使うと、日本の「通貨及証券模造取締法」に抵触するおそれがあるため採用していません。詳しくは本改修の報告メッセージを参照してください。

ゲーム名を変更したい場合は `js/constants.js` の `GAME_TITLE` を書き換えるだけで、画面表示・タブタイトルの両方に反映されます。

---

## 遊び方

1. 画面下の **TOOLS** から `FIRE`（燃やす）か `TEAR`（破る）を選ぶ。
2. ゲームエリアの紙幣をタップ／クリック、またはドラッグ・スワイプする。
3. 紙幣が完全に壊れると、その額面が **TOTAL DESTROYED** に加算される。
4. 紙幣がなくなったら **RESET** で補充できる。

制限時間・勝敗・ミッションはありません。純粋に壊して楽しむゲームです。

### 操作方法

| 環境 | 操作 |
| --- | --- |
| PC | マウスクリック／ドラッグ |
| スマホ | タップ／スワイプ／ドラッグ |

キーボードのみでも操作できます（紙幣に `Tab` で移動し `Enter` / `Space` で、選択中のツールを発動）。

---

## ツール

| ツール | 効果 |
| --- | --- |
| 🔥 FIRE | クリック（またはドラッグ開始）した紙幣に着火。着火後は自動で燃え進み、燃え尽きると消滅してスコア加算。 |
| ✋ TEAR | 紙幣の上をドラッグ／スワイプした距離ぶんだけ破れが進む。左右2つの破片に分かれていき、破れきると消滅してスコア加算。 |

数値バランス（燃焼速度・破れやすさなど）は `js/constants.js` の `FIRE_CONFIG` / `TEAR_CONFIG` で調整できます。

---

## スコア計算

紙幣の額面をそのまま **TOTAL DESTROYED** に加算するだけのシンプルな仕様です（コンボ倍率などはありません）。

例：1,000円札を破壊 → +1,000 ／ 5,000円札を破壊 → +5,000 ／ 10,000円札を破壊 → +10,000

紙幣は `burnProgress` と `tearProgress` の2つの進行度（どちらも0〜100）を持ち、**どちらか一方が100に達した瞬間に一度だけ**スコアへ加算されます（`note.destroyed` フラグにより二重加算を防止）。

## 紙幣画像の扱い方

実在の紙幣写真は使用していません。`js/notes.js` の `noteFaceHTML()` が、額面ラベル・行名（OKAPO CENTRAL BANK）・架空のシリアル番号・幾何学模様・肖像シルエットをCSS/SVGでその場生成しています。

- 1,000円 / 5,000円 / 10,000円 の3種類（`js/constants.js` の `DENOMINATIONS`）
- 額面ごとのインク色は `css/style.css` の `--note-1000-ink` / `--note-5000-ink` / `--note-10000-ink` で管理
- 額面や配色を増やしたい場合は、この2箇所に追記するだけで反映されます

破る演出（TEAR）は、同じ絵柄を複製した2つの破片（`.okapo-note-half--a` / `--b`）をギザギザのclip-pathで噛み合わせておき、`tearProgress` に応じて左右に引き離すことで表現しています。

---

## 炎の表現について

ストック素材（PNG画像）は使用していません。ライセンスの再配布条件が確認できない画像を公開サイトに組み込むのを避けるため、`css/style.css` 内でCSSアニメーションのみによる多層の炎（コア・中間層・先端・グロー、それぞれ別アニメーションで揺らぎを付与）を実装しています。`.okapo-note-flame-core` / `-mid` / `-tip` / `-glow` が該当します。

## localStorageに保存するデータ

キー: `okapoMoneyCrash.v1`

| 項目 | 内容 |
| --- | --- |
| `totalDestroyed` | これまでに破壊した合計金額 |

これ以外のデータ（ベストスコア・ランク・実績など）は保存していません。

```
  js/

    ui.js          … DOM表示とgame.jsの橋渡し
    main.js        … 起動処理
  assets/
    sounds/        … （現状未使用の予約ディレクトリ）
  README.md
```

## Netlify / Vercelでの公開方法

このリポジトリは静的サイトとしてデプロイされています。`money-burner/` フォルダをそのままリポジトリに含めてpushすれば、追加のビルド設定なしで `https://okapo-site.netlify.app/money-burner/` として公開されます。Vercelの場合もFramework Preset: Other・ビルドコマンドなしで、同様にそのまま配信できます。外部ライブラリのCDN読み込みは行っていません（フォントのみGoogle Fontsを使用）。
